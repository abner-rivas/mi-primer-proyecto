# Mi primer proyecto

Proyecto HTML introductorio desarrollado como práctica para aprender el flujo básico de control de versiones con Git y GitHub. Contiene una página web sencilla con una lista de temas de aprendizaje.

## Tecnologías utilizadas

- HTML5
- Git
- GitHub

## Instrucciones para abrir el proyecto

1. Clona o descarga este repositorio en tu computadora.
2. Abre la carpeta `mi-primer-proyecto`.
3. Haz doble clic en el archivo `index.html` o ábrelo directamente desde tu navegador web preferido.
